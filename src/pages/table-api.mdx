# Tables API

SonicJs automatically generates CRUD based API endpoints for each table defined in your [schema](/tables#schema). It does this without generating code (a good thing!) and
can be easily extended or modified based on your needs. {{ className: 'lead' }}

This includes the ability to:

1. Get a list of records.
   - Records can optionally filtered
   - Records can optionally be sorted
   - Records can optionally be paged
1. Get an individual record by id
1. Post to create new record
1. Put to updated an existing record
1. Delete to remove an existing record

## The Users table

For our examples below, we'll use the `users` table defined here: `/src/db/schema.ts`, however the API is dynamic based on your custom
defined [schema](/tables#schema), so all of the below endpoints are created for each table in the schema.

There is an admin page in the SonicJs UI that will list out the generated APIs for your reference:

## Example: List users table records {{ tag: 'GET', label: '/api/v1/users' }}

<Row>
  <Col>

    ### Optional attributes

    <Properties>

      <Property name="offset" type="integer">
        The offset used for paging results.
      </Property>
      <Property name="sort" type="array">
        The fields used for sorting results. The sorting order can be defined with:<br/>

:asc for ascending order (default order, can be omitted) or :desc for descending order.<br/>
Examples:<br/>
**Sort on single field:**<br/>
GET `/api/v1/categories?sort=title`<br/>
**Sort on multiple fields:**<br/>
GET `/api/v1/categories?sort[0]=title:desc&sort[1]=body:asc`<br/>

</Property>
<Property name="filters" type="array">
Queries can accept a filters parameter with the following syntax:<br/>
GET `/api/v1/:tableName?filters[field][operator]=value`<br/>
Examples:<br/>
**Filter on single field:**<br/>
`/api/v1/categories?filters[title][$eq]=hello`<br/>
**Filter on multiple fields:**<br/>
`/api/v1/categories?filters[title][$eq]=hello&filters[body][$contain]=world`

The following operators are available:<br/>

## Create a record {{ tag: 'POST', label: '/api/v1/user' }}

<Row>
  <Col>

    This endpoint allows you to insert new records into your database tables.

    Note that you do not need to supply created_on and updated_on fields as their values are generated automatically by SonicJs.

    ### Required attributes

    <Properties>

  <Property name="data" type="string">
    The Json string containing the content data. This can include all or just some of the fields in your table. It must however included
    any required (not null) fields.
  </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="POST" label="/api/v1/users">

```json {{ title: 'body' }}
{
  "data": {
    "name": "John",
    "email": "john@somewhere.com",
    "role": "admin"
  }
}
```

    </CodeGroup>
