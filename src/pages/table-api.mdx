# Tables API

SonicJs automatically generates CRUD based API endpoints for each table defined in your [schema](/tables#schema). It does this without generating code (a good thing!) and
can be easily extended or modified based on your needs. {{ className: 'lead' }}

This includes the ability to:

1. Get a list of records.
   - Records can optionally filtered
   - Records can optionally be sorted
   - Records can optionally be paged
1. Get an individual record by id
1. Post to create new record
1. Put to updated an existing record
1. Delete to remove an existing record

## The Users table

For our examples below, we'll use the `users` table defined here: `/src/db/schema.ts`, however the API is dynamic based on your custom
defined [schema](/tables#schema), so all of the below endpoints are created for each table in the schema.

There is an admin page in the SonicJs UI that will list out the generated APIs for your reference:

GET `/api/v1/:tableName?filters[field][operator]=value`<br/>
Examples:<br/>
**Filter on single field:**<br/>
`/api/v1/categories?filters[title][$eq]=hello`<br/>
**Filter on multiple fields:**<br/>
`/api/v1/categories?filters[title][$eq]=hello&filters[body][$contains]=world`
